# E60 阶段归因与缓存对照

## 结论

**原始分数已经出现后段判别能力下降；单纯校准阈值或更换启动方式未解决退化。当前保持正式主链。**

基线全段 **AUC 0.8315 / F1 0.7742 / bACC 0.7824**；块4–5 **AUC 0.7601 / F1 0.7130 / bACC 0.7282**。启动均值明显损伤 bACC，弱融合收益不足以支持部署。

## 数据与口径

- 复用 E53 的57人LOSO融合分数，标签及时间块来自原有 sliding1 缓存，按与 `loso.load()` 相同的时间顺序对齐。
- 每人先算指标，再对被试等权平均；高分对应 task，零阈值预测条件为 score > 0。
- 早段为 block <= 2，后段为 block >= 4。034没有早段数据，早段及早晚配对用56人，全段及后段用57人。因此不能直接将两列宏均值相减当成配对差。
- 标签和 block 只用于离线评价，不输入在线后处理。缓存不包含原始流中的所有无标签间隙，不能据此宣称完成真实BDF流式验证。

## 阶段归因

表内顺序均为 **AUC / F1 / bACC**。

|阶段|全段（57人）|早段（56人）|后段（57人）|
|---|---|---|---|
|raw|0.8191 / 0.7481 / 0.7617|0.8205 / 0.6764 / 0.7571|0.7552 / 0.6988 / 0.7183|
|detrend|0.8184 / 0.7562 / 0.7608|0.8186 / 0.6799 / 0.7577|0.7568 / 0.7068 / 0.7183|
|detrend → HMM|0.8315 / 0.7742 / 0.7824|0.8413 / 0.7215 / 0.7905|0.7601 / 0.7130 / 0.7282|

raw后段减早段的配对 AUC 均值为 **−0.06938**，被试级配对 bootstrap 95%区间 **[−0.13834, −0.00596]**（固定种子20261107，5000次重采样，未做多重校正）。33人改善、23人下降，均值下降主要受严重退步个体影响，不能表述为所有人共同退化。早晚类别构成不同，F1变化不能单独用于判断判别信息变化。

HMM总体提供净收益，但26/57人后段 AUC 或 F1 低于 detrend，满足小比例弱融合的探索条件。这不是HMM普遍有害的证据。

逐人两类分数中心、标准差、间距和标准化间距见 `attribution_subjects.csv`；各阶段逐人变化和最差5人见 `attribution.json`。这些是分数层面的关联诊断，不证明疲劳、电极状态等生理原因。

### 参数定义

- 阈值在[-12,12]、步长0.01的固定网格中选取，以其他56人的全段宏bACC最大为目标；平局选最接近0的阈值。每个目标被试阈值冻结，不读取其标签。常数阈值平移不改变该被试AUC。
- 启动长度 S=60或120；n从1计数，a=1−0.5^(1/1200)，u=clip((n−S)/S,0,1)，alpha_n=(1−u)/n+u*a。前S帧为累计均值，S至2S帧平滑过渡到慢速EMA；首帧即输出，不回改历史。
- 弱融合采用 (1−w)×HMM/RMS_HMM + w×detrend/RMS_detrend；RMS由其他被试的逐人均方再等权平均确定。仅比较w=0.05/0.10，另保存其他被试全段bACC选比例的探索结果。

### 个体保护

启动60帧导致034后段 bACC **下降0.2512**、F1下降0.1862；启动120帧导致034后段 bACC **下降0.2393**。全段AUC最差下降发生于050：60帧下降0.0607，120帧下降0.0696。后段F1均值上升不能掩盖这些退步。

## 验证边界与后续

**本节的校准和弱融合均为缓存探索，不是完整嵌套验证。** 虽然参数选择排除了当前目标被试，但其他被试缓存的生成模型曾用当前目标被试训练。反复使用同一批LOSO结果探索也存在选择偏差。

- 阈值校准未将dual的后段排序收益转化为可靠的综合改善。
- 不采用启动均值替代首帧初始化；不因不足0.0002量级的弱融合收益替换正式主链。
- raw下降支持进一步执行被试×时间块均衡训练；真实训练折中心和训练折阈值须依靠独立重训，与本报告的缓存结果分开报告。
- 本实验没有候选进入真实BDF、chunk一致性和前缀不变性验证，不作部署有效性声明。
