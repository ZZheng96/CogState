# E43：高低表现组、方向反转与无标签画像路由

## 结论

1. 高/低组差异很大，值得分组诊断；但按测试成绩分组只能解释现状，不能直接用于部署。
2. 高组28人在 E17+HMM 后已经接近整体0.9；低组29人的主要问题是**后段方向/条件关系退化**，不是缺少更复杂的时序平滑。
3. 当前前4段纯无标签画像无法可靠预测高低组：留一 AUC 0.532、bACC 0.542，接近随机。因此暂不能把“高分模型/低分模型自动路由”作为已验证方案。

## 分组口径

使用 E42 的57人 LOSO 基线全段 bACC，中位数为 **0.784862**。高组为高于中位数的28人，低组为其余29人。切点只由本次结果确定，不针对个人调阈值。该分组使用测试标签，仅用于诊断。

## 高低组结果

| 组/阶段 | bACC | AUC | F1 |
|---|---:|---:|---:|
| 高组28人，基线全段 | 0.8726 | 0.9395 | 0.8697 |
| **高组，HMM全段** | **0.8871** | **0.9481** | **0.8837** |
| 高组，HMM前600帧 | 0.8571 | 0.9088 | 0.8395 |
| **高组，HMM块4–5** | **0.8936** | **0.9570** | **0.8938** |
| 低组29人，基线全段 | 0.6546 | 0.7029 | 0.6307 |
| 低组，HMM全段 | 0.6709 | 0.7152 | 0.6403 |
| 低组，HMM前600帧 | 0.7378 | 0.7933 | 0.6661 |
| **低组，HMM块4–5** | **0.5625** | **0.5632** | **0.5204** |

低组前600帧经 HMM 尚有0.7378，但后段降至0.5625；高组则从前600帧0.8571升至后段0.8936。这说明低组不是简单地“从开头就完全没有信号”，而是随时间出现了更严重的类间关系变化。

HMM 全段增益在高/低组分别为 +0.0145/+0.0163；但后段增益为高组 +0.0163、低组 **-0.0024**。HMM 对低组后段没有解决问题。

## 方向反转者

基线全段 AUC<0.5 的4人为：**004、009、010、050**。

| 4人方向反转组 | bACC | AUC | F1 |
|---|---:|---:|---:|
| 基线全段 | 0.4944 | 0.4754 | 0.4101 |
| HMM全段 | 0.5046 | 0.4811 | 0.4075 |
| 基线块4–5 | 0.3659 | 0.2344 | 0.2198 |
| HMM块4–5 | **0.3254** | **0.2092** | **0.1536** |

对这4人，HMM 在后段反而放大错误。这直接支持“先修复方向，再做平滑”的判断。

## 无标签画像能否预测组别

仅使用 `subj_profile.py` 中由前4段无标签数据可计算的18个字段：相对频带、RMS、平坦/尖峰/坏段、50Hz、EMG、原始频带功率和幅值等。排除 `d_*`、`auc_*`、`alpha_react`、`drift_*`、`sim_*` 等标签依赖字段。

固定逻辑回归进行57人留一：

- **AUC 0.5320**
- **bACC 0.5425**
- 预测为高组比例 0.421

因此当前画像不足以可靠路由。E24 的 Ward 分组达到约0.823，但其有效画像轴使用了校准标签和校准效应方向；不能与这里的纯无标签画像混用。

## 情绪识别排行榜的参考价值

| 榜单思路 | 对本题的价值 |
|---|---|
| DE/频带功率 + LR/SVM/集成 | 与当前路线同族。E17 已含多分辨率 STFT 的 log/relative band power；高斯子带的微分熵与对数功率只相差常数/系数，单纯补DE通常不会增加新信息 |
| STFT/CWT 时频图 + CNN/ViT | 当前已有多尺度时频特征，既往深度模型未超过手工特征；只有全新表征学习而非简单换输入形状才可能带来差异 |
| GAF/MTF 波形转图 | 主要是表征变换，不解决跨被试方向反转，优先级低 |
| Topomap | 依赖多通道空间位置，本题单通道不适用 |
| 高分组/低分组分别建模 | 有潜在价值，但必须先获得合规且准确的目标组别预测；当前纯无标签画像还不具备这个能力 |

## 下一步建议

1. **高组保持现有模型**，重点研究低组，不再为了高组继续堆集成。
2. 低组以“前600帧到后段的方向漂移”为主要终点，按人展示 AUC 和类别方向，而不只比较 bACC。
3. 若有合法校准标签，优先使用 `drift_sign/auc_xblk` 等漂移指标选择本人模型、池化模型或关闭HMM；E24 已证明这类信息比纯无标签画像更有效。
4. 若无校准标签，先做在线变化检测和保守HMM门控，避免方向反转时持续放大错误；它只能防损，不能代替方向修复。
5. 只有在找到可在线计算、留一验证显著高于随机的路由特征后，才值得正式训练高/低组两套模型。
