# E32c：G2 与 G3 合并（margin 融合 + 门控）

## 目的
E32b 的分数相加最多只到 min .843。本实验换两种方法，看能否用一个配方覆盖 G2（016 013 006 058 014 037 036 008）和 G3（018 048 056 021 038 059）共 14 人，并让每人 bACC ≥ 0.9。

## 方法
1. **Margin 融合**（e32c.py，oracle）
   - 两个分数先各减自己的因果阈值：dA = sA − thrA，dB = RB − thrB。
   - 可选：除以过去 S 帧的因果 std 做缩放，S ∈ {不缩放, 300, 1200}。
   - 判决规则：D = w·dA + (1−w)·dB > 0。
   - 搜索范围：sA ∈ {RA, RA′（E32b 简化版）}，thrA 和 thrB 各取 85 种，w 取 0 到 1 共 21 档。合计 2×3×85×85×21 ≈ 91 万个配置。
   - 这种做法让两组各用自己的阈值窗口（m300 和 m1200），针对的是 E32b 发现的阈值冲突。
2. **个体门控**（e32c_gate.py）
   - 先算 oracle 上限：每人取 RA@m300 和 RB@m1200 中较好的一个。
   - 再找合规的门控统计量，判断它能否用单一阈值把 G2 和 G3 分开。统计量只用校准块标签或测试流的无标签数据：
     - 校准块 AUC 差（块 0–3 全部、块 2–3）；
     - 校准段内 RA 与 RB 的相关；
     - 测试流前 300、600、1200 帧中 RA 与 RB 的相关和 std。
- 自检：w=1 时 G2 RA@m300 = .9015，w=0 时 G3 RB@m1200 = .9002，与 E31b 一致。

## 结果

| 范围 | 最优配置 | min bACC | bACC | AUC | F1 |
|---|---|---|---|---|---|
| G2 | RA′@m300 ⊕ RB@q300_0.25，w=.95，σ300 | **.9068** | .9201 | .9653 | .9204 |
| G3 | RA@q600_0.75 ⊕ RB@m1200，w=.10，不缩放 | **.9021** | .9178 | .9673 | .9191 |
| G2∪G3 margin 融合 | RA@m300 ⊕ RB@t0，w=.60，σ300 | .8692 | .8972 | .9541 | .8999 |
| G2∪G3 门控 oracle | 每人取 RA@m300 或 RB@m1200 中较好者 | .9002 | | | |
| （参照）E32b 叠加 | RA+½gemg_k200@m300 | .8432 | .8921 | .9598 | .8921 |

合并后的逐人 bACC：016 .934、013 .903、006 .888、058 .916、014 .879、037 .872、036 .924、008 .889、018 .953、048 .880、056 .882、021 .896、038 .876、059 .869。

两个配方在各自组内都达标，但换到对方组就不行：
- RB 在 G2 上，008 只有 .40，037 只有 .63；
- RA 在 G3 上只有 .83–.87。

门控统计量都分不开两组。下表的分隔余量为 G2 与 G3 取值区间的间隔，负值表示两组区间重叠：

| 统计量 | 分隔余量 |
|---|---|
| 校准块 AUC 差（块 2–3） | −.007 |
| 校准段 RA 与 RB 的相关 | −.034 |
| 测试流前 N 帧的相关 | ≤ −.086 |
| std | ≤ −.24 |

校准块 AUC 对两个配方都接近 1（组件在校准块上训练，属样本内），所以分不出哪个配方更好。

## 结论
- Margin 融合把并集 min 从 .843（E32b）提到 .869，仍低于 .9，**未实现合并**。
- 个体门控的上限能到 .9002，但找不到合规的分配统计量，不能作为单一方法使用。
- 副产品：G2 换成 RA′@m300 ⊕ RB@q300_0.25（w=.95，σ300）后，min 从 .9033 升到 .9068；G3 用 margin 融合后，min 从 .9002 升到 .9021。两组的安全余量都略有增加。
- 分组结构不变，整体仍为 57/57 达标（oracle）。
