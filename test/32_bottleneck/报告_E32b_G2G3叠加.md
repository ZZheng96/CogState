# E32b：G2 与 G3 方法叠加

## 目的
G2（016 013 006 058 014 037 036 008）和 G3（018 048 056 021 038 059）的配方都由 sim/idx/joint 组件 z 平均构成。检验把两组的组件叠加后，能否用一个配方覆盖 14 人且每人 bACC ≥ 0.9。

## 方法（e32b.py，oracle，85 种因果阈值）
- 组件共 7 个：idxgdwt10、sim4390_C0.001、k4390_w0.6、ghilbert_k200（G2），sim4390_C0.01、b23r400_C0.1、sim800_C0.001（G3）。
- A 族：7 个组件的 127 个非空子集，取 z(和)。
- B 族：w·RA + (1-w)·RB，w 取 0 到 1 共 11 档，其中 RA 为 G2 原配方，RB 为 G3 原配方。
- C 族：RA 或 RB 加上 ½ 个任意 base 组件。
- 补查：E31b 缓存的 1152 个 b|pool 配置（含 pool⊕组件）× 85 阈值。
- 自检：G2 RA@m300 = .9015，G3 RB@m1200 = .9002，与 E31b 一致。

## 结果

| 范围 | 最优配方 | 阈值 | min bACC | bACC | AUC | F1 |
|---|---|---|---|---|---|---|
| G2 | A: idxgdwt10+sim4390_C0.001+ghilbert_k200 | m300 | **.9033** | .9202 | .9654 | .9194 |
| G3 | B: RB（原配方） | m1200 | .9002 | .9152 | .9682 | .9186 |
| G2∪G3 叠加 | C: RA+½gemg_k200 | m300 | .8432 | .8921 | .9598 | .8921 |
| G2∪G3（E31b pool 1152 配置） | 第 779 号配置 | m600 | .8384 | | | |

叠加后的瓶颈是 G3 成员。在 RA 系配方下，048、056、059、006 只有 .84–.85。G3 最适合的阈值是长窗口 m1200，G2 是 m300，两组的阈值需求也不一致。

## 结论
- 两组配方的组件相近，但叠加后 min 只有 .843，**无法合并**，17 组结构不变。
- 副产品：G2 去掉 k4390_w0.6 后，min 从 .9015 升到 .9033（bACC .9202 / AUC .9654 / F1 .9194），可替换 G2 的配方。
- 整体指标不变：bACC .9217 / AUC .9682 / F1 .9219，57/57 达标（oracle）。
