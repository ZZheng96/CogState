# E31a：并集统一配方搜索（oracle 口径，因果配方）

日期：2026-11-05。脚本 `test/31_integrate/e31a.py`，结果 `e31a.json`（含 top50 与逐人指标），日志 `e31a.log`。全程 GPU（RTX 3080 Laptop 16GB），总耗时 128 s。

## 方法

- **目标**：为并集 U1 = {025, 028, 010, 053, 043, 054}（E26 的 G6+G11）与 U2 = {011, 004, 055, 052}（G7+G13）各找一个「分数配置 + 一个共享因果阈值」，使并集 min 测试 bACC（块 4–5）≥ 0.9。
- **pool 分数网格（72 配置）**：w∈{300,600,1200}（本人记录内过去 w 帧因果均值重定心，训练、测试同口径），α∈{.35,…,.7}（本人校准块权重占比），τ∈{inf,0.2,0.5}（其余 56 人按校准效应方向余弦相似度加权 wo_j ∝ exp(cos(d_j,d_本人)/τ)，d 为校准块 (R,T) 对均值差方向、在 w 重定心空间计算；034 无校准效应对照取 cos=0；τ=inf 退化为 E28 等权 pool）。训练为 E28 同款类平衡加权 LBFGS LR（λ=0.01），多配置列批量求解。
- **组件（15 个）**：cands_scores.npz 的 goth_k200、gemg_k200、ghilbert_k200、gstft_k200、idx10、idxgdwt10、own200_C0.1、b23n100_C0.1、b23n400_C0.1、k4390_w0.6、k1600_w0.85、sim800_C0.01、sim4390_C0.01，加按 E25/excl.py 定义重建的 sc99999_k200、jw0.95_k1600_C0.1。
- **候选分数（1152 个/人）**：72 个 pool 单配置 + 全部 pool×组件两两 z 平均（相加后按本人校准段重标准化，同 E26 zpair）。
- **评估**：e26lib 85 种因果阈值（t0 / 过去 w 帧均值 m{w} / 分位数 q{w}_p，仅无标签过去数据）；oracle 口径同 E26——同一阈值下并集成员 min 测试 bACC 最大者胜。
- **扩展（U1 触发，min<.895）**：top20 pool × top6 组件的 C(6,2)=300 个三配置 z 平均，未改善。

## 正确性自检

- 组件重建：054 专属配方 z(sc99999_k200+jw0.95_k1600_C0.1)|t0 → bACC **0.919736**，与 excl.json 完全一致（AUC 0.9178，F1 0.9223）。
- 锚点 b\|pool\|w600\|a0.5（τ=inf，LOSO 选阈值）在 U1 逐人 bACC 与 e28.json 最大偏差 **0.0057** ≤ 0.01（025 −0.0034 / 028 ±0 / 010 −0.0017 / 053 −0.0035 / 043 −0.0057 / 054 +0.0001）；w300 锚点在 U1+U2 最大偏差 0.0035。偏差源于批量 LBFGS 共享步长，可忽略。

## 是否达成与瓶颈分析

- **U2 达成** min≥0.9：最优 z[b|pool|w300|a0.7|tinf; b23n400_C0.1]@m300，并集 min .9268，宏 bACC .9448 / AUC .9747 / F1 .9418。瓶颈 004（.9268，其余三人都 ≥.937）；b23n400_C0.1（块 2–3 效应量前 400 维 LR）把 011 从 .887 抬到 .956，是关键组件。
- **U1 未达 0.9**：最优为纯 pool 单配置 b|pool|w600|a0.4|tinf@m300，min .8909（宏 bACC .9132 / AUC .9650 / F1 .9114），瓶颈 **043（.891）与 053（.894）**，054（.898）也在 0.9 下。单人 oracle 上限：054 仅 .9213、053 .9368、043 .9429（025/028/010 均 ≥.974），即并集 min 的理论上限约 .92，当前搜索空间内 0.9 不可达。τ=0.2/0.5 的相似度加权均未进 U1 top10（等权 pool 已最优）；组件 z 平均反而稀释 pool（top7–10 均低于纯 pool）。相对 E26 现配方（w600a0.5，min .8872），α=0.4 把 min 抬到 .8909，但缺口仍在 043/053/054 三人本身——需要针对这三人的新分数族而非聚合权重调整。
