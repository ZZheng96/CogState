# E33：校准响应指纹 → 配置路由

## 结论

- **E23 严格嵌套 LOSO（模型族与超参均在内层选择）**：bACC **0.7327**，AUC **0.8014**，F1 **0.7273**，n≥.9=5/57；目标 .9 未达到。
- E23 各预设路由族分别嵌套选超参后，探索性最高为 `soft_all_raw`：bACC 0.7669，AUC 0.8254，F1 0.7695。每人预测均严格折外，但家族间最高值属于事后比较，总体结论仍以上一行的 omnibus 为准。
- E23 测试标签 oracle 上限：bACC 0.9387，AUC 0.9721，F1 0.9387；该数值仅作上限，不能部署。
- **E28 严格嵌套 LOSO（模型族与超参均在内层选择）**：bACC **0.8141**，AUC **0.8845**，F1 **0.8061**，n≥.9=16/57；目标 .9 未达到。
- E28 各预设路由族分别嵌套选超参后，探索性最高为 `soft_all_raw`：bACC 0.8364，AUC 0.9042，F1 0.8194。每人预测均严格折外，但家族间最高值属于事后比较，总体结论仍以上一行的 omnibus 为准。
- E28 测试标签 oracle 上限：bACC 0.9461，AUC 0.9749，F1 0.9457；该数值仅作上限，不能部署。
- E28 最佳单族较固定 pool 锚点的 bACC 增量为 +0.0150；其57折均选 k=40、α=0，提升来自原始响应指纹的距离倒数40-NN，而非校准bACC凸混合。

既有固定通用参照约为 .821（E28 pool 锚点）和 .836（E31b 最优单配置的 LOSO 阈值口径；其全配置嵌套选择为 .8197）。本实验不把 oracle 或外层事后择优当成总体严格结果。

## 严格评估协议

- 指纹：本人校准块的逐配置×因果阈值 bACC；`all` 为块0–3整体，`blocks` 另拼接块0–1与块2–3。034 仅块3且只有 task 类，bACC 指纹不可定义，所有响应模型严格回退为其他56人的全局均值。
- 路由：距离倒数 kNN、软 kNN+校准表现凸混合、多输出对偶岭回归、PCA 主成分回归。
- 每个外层留出一人；模型族、特征变体和超参只由其余56人的内层 LOSO 宏 bACC 选择。岭/PCR 内层 LOO 使用帽子矩阵精确计算，不使用内层留出者的测试标签拟合。
- 外层目标的测试标签只用于选择完成后的 bACC/AUC/F1 评分；oracle 表是唯一允许按目标测试标签选配置的对照。
- 分数与阈值直接复用 E23/E28 缓存；校准响应计算在 GPU 上完成并缓存。
- E28 保存分数为 float16；同一 half 输入下本实现与 E26 原评估器逐配置阈值 bACC 差为0，与原 float32 EV 的小差异仅为缓存量化，报告在自检中单独列出。
