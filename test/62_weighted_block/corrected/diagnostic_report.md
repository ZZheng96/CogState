# E61 / E62 修正后六折诊断

## 范围与口径

仅运行 004、009、010、018、034、050 六个诊断折，**不是全57折泛化评估**；每折仍使用其余56名被试训练，目标被试隔离。实际ID无 `sub-` 前缀。GPU串行执行 E61 → E62，运行前未发现旧 e59/e62 Python 进程，无需停止进程。未修改原始数据。

early12 为 block<=2，late45 为 block>=4；034 无 early12，早期宏平均仅含5名，其 full/late45 仍参与汇总及配对。表中指标顺序均为 **AUC / F1 / bACC**，宏平均按被试等权；不存在类别的指标记缺失。

E61 使用 sklearn AUC、严格 dual=raw-lm-.5*clip(sm-lm,-.5,.5)，NPZ 保存实际 pooled_center=center_lr/std_lr+center_mlp/std_mlp。阈值在训练被试因果后处理分数上，以 searchsorted 计算宏bACC选择（-4至4，步长.1，同分取近0）；这是训练内拟合而非内层OOF，存在乐观性。E62 阈值固定0；MLP预测 no_grad，移除无用排序，配对不因早期缺失丢弃其余分段。

两个实验输出均在独立 corrected 目录，未复用旧错误结果。E62 baseline **明确复用本次E61同设置原始分数**：相同56人训练、特征、LR C=.001、MLP三种子0/1/2、30 epochs及训练池标准差；NPZ目标与训练名单已匹配。E62重新训练 weighted 模型。E61 baseline_first 的阈值经训练选择，因此其F1/bACC与E62固定0 baseline略有差异，AUC相同。

## 复现与产物

在仓库根目录依次执行：

```powershell
.venv/Scripts/python.exe test/61_trainfold_initialization/e59_trainfold.py --targets 004 009 010 018 034 050
.venv/Scripts/python.exe test/62_weighted_block/e62_weighted.py --targets 004 009 010 018 034 050 --baseline-dir test/61_trainfold_initialization/corrected/folds
```

- E61：`test/61_trainfold_initialization/corrected/e61_results.json`，含全部变体逐被试分段指标及阈值；`corrected/folds/` 内6个JSON及6个NPZ（原始分数、训练名单、标准差与中心）。
- E62：`test/62_weighted_block/corrected/e62_results.json`，含全部变体逐被试指标及12条配对记录；`corrected/folds/` 内6个JSON及6个NPZ（baseline和weighted原始分数）。
- 两条命令均使用CUDA且退出码0，无运行错误。E61逐折训练与后处理耗时约22–24秒，E62约19–20秒。没有运行全57折，没有提交git。
