# E78 固定 signed raw 方向的有界幅度六人变体

仅使用 E76 缓存。两候选均固定 w=.5 raw 的符号，不改变方向；只用 |conditioned|/|raw| 调节幅度，并统一因果 EMA1200 + forward HMM300。

## 候选定义

- `e78_clip_ratio`：比例裁剪到 [0.75, 1.25]。
- `e78_convex_ratio`：裁剪比例向1收缩一半，范围 [0.875, 1.125]。
