# E78 固定 signed raw 方向有界幅度 57 人验证

严格复用 E76 的 57 个逐折缓存；每个目标被试独立计算，统一因果 EMA1200 + forward HMM300。方向固定为 w=.5 raw，仅调节幅度。

## 协议

- `e78_clip_ratio`：`|conditioned|/|raw|` 裁剪到 `[0.75, 1.25]`。
- `e78_convex_ratio`：裁剪比例向 1 收缩一半，范围 `[0.875, 1.125]`。
- 每折预测及标签保存为独立压缩 NPZ，未覆盖六人结果。

## 结论

57人验证中，late AUC最高的候选为 `e78_convex_ratio`。clip ratio 的 full AUC/F1/bACC = 0.836680/0.780672/0.787682；late AUC/F1/bACC = 0.756969/0.713935/0.728346。
