# E24 聚类分组、组内统一方法

数据与候选沿用 E23（57 人，块 0–3 校准、块 4–5 测试；候选为 1653 个配置 × 8 种因果阈值）。推理部分全部严格因果，窗口不超过 6 s。“可部署”的含义是：给留出被试 i 选方法时，只用 i 的校准画像，加上其他被试的历史测试结果。

脚本（`test/24_cluster/`）：`clib.py`（公共函数：GPU 上的 z 平均叠加评估，带缓存）、`resp_cluster.py`（上界）、`prof_cluster.py`（画像分组、组内 top1/贪心叠加/邻组叠加）、`soft_cluster.py`（核权重软分组）、`nested_select.py`（分组方案本身也用 LOSO 选）、`groups_desc.py`（组描述）。日志和 json/csv 产物放在同一目录。

核对：k=1（全体一组）top1 的 LOSO bACC 为 .712，与 E23 全局单一最优配置一致。StackEval 单配置评估与 E23 缓存逐项一致，误差为 0。

## 2. 可部署分组（画像聚类 + 组内 LOSO 选方法）

特征集：
- cal：全部校准画像列。
- ax3：sim_top10、drift_sign、d_emg。
- ax5：ax3 加 drift_cos、d_top20。

聚类算法为 Ward 层次聚类和 KMeans，k=1..8。

组内方法：
- top1：同组其他人平均测试 bACC 最高的 (配置, 阈值)。
- greedy：在同组其他人上做贪心前向 z 平均叠加，m=1..5，池为前 10 个配置，m 由组内留二 LOSO 决定。
- blend：本组 top1 与画像质心最近的邻组 top1 做 z 加权叠加，a∈{0,.25,.5}，由 LOSO 选。

- 从 1 组分到 3–6 组，bACC 提升约 +.10，这是分组本身带来的收益。分到 8 组后组太小（3–5 人），组内选法的噪声变大，收益回落。
- 组内贪心叠加只在大组（k≤2）或个别情况下好于单配置，幅度约 ±.01。叠加没有带来稳定收益。
- 邻组叠加 blend 选的权重随 k 变化。k=8、k=2 和 ax5 k=3 时几乎总选 a=0，即不叠加。在 k=4–5 等中间 k 上多选 a=.25–.5，此时比 top1 高 0–.01，例如 ax3 k5 从 .809 到 .818、ax5 k5 从 .804 到 .809。在 k=6–8 上则持平或更差。总体上没有超过最优的 top1。

## 4. 软分组

软分组用高斯核按画像距离给其他人加权，取加权 bACC 最高的 top-m 个配置叠加，带宽 h 和 m 都由 LOSO 选。h 多数选在 0.25–0.5 倍中位距离，相当于很局部的近邻。最好的是 ax3：.799 / AUC .871 / F1 .797 / n≥.9 12。它比硬分组 ax5 k=3 低 .026，与 E23 的 kNN 元选择器（.789）相当。

解释：
- A 组：块 0–1 和块 2–3 的效应方向相反，与他人方向相似度也低。胜出方法是“相似他人模型 + 因果中位数阈值”。用他人模型可以避开本人校准方向的漂移，中位数阈值可以吸收偏置漂移。
- B 组：方向一致，但可分度一般。胜出方法是“KNN 型他人集成 + 30 s 分位数阈值”。
- C 组：EMG 组 d′ 大、与他人相似度高。胜出方法是“KNN 集成 + 相似他人”，零阈值就够。

这与 E23 的三个个体差异主轴吻合。A 组即 E23 的“反转人群”，他们的 ens8 仅 .684，组内选法能提高到 .789，但离 oracle .937 仍远。

ax3 Ward k=6 的分组更细：方向一致、EMG 强的人被分成两组，分别为 6 人（ens8 .894，LOSO .881）和 12 人（LOSO .863），方向反转的人被分成三组，分别为 5、12、3 人（LOSO .767–.800）。完整内容见 `groups_desc.json`。

## 6. 结论

1. 组共用方法的上界：2 组约 .85，4 组约 .88，8 组约 .90。n≥.9 在 8 组时可到 34–41 人，所以“少数几种方法覆盖大多数人”在原理上成立。
2. 只用校准画像做分组，最好约 .82：ax5 Ward k=3 为 .825，嵌套选择为 .823，n≥.9 为 15–16。比 E23 岭回归 .790 高约 3 个点（p=.11，不显著），比 ens8 高 7.5 个点（p<.001）。与上界 k=3 的 .87 相比还差 .05，差距来自组分配错误，主要在 A 组（反转组）。
3. 组内多方法贪心叠加、邻组叠加、软核权重，都没有超过“硬分 3 组 + 组内单配置”。叠加的收益被组小、选择噪声大抵消了。
4. 建议的可部署方案：用校准画像的 5 个轴做 Ward 3 组，每组用组内历史最优的单配置及其阈值，即上面胜出方法列中的 3 个配置。要达到 n≥.9 的目标，仍然需要能在校准段识别 A 组测试方向的新信息。
