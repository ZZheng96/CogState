# E81 训练折内部分特征维度 polarity augmentation（六人严格 LOSO 诊断）

训练折保留原始样本，并追加一份仅翻转固定随机50%特征维度的副本，标签不变；目标折不增强、不参与参数估计或选择。baseline 与增强组均为 LR C=.001 + 三个 MLP seed 均值，尺度仅由训练折输出估计，统一 E74 的 EMA1200+前向HMM300。未做 score 后处理门控。

## 结论

六人诊断结果见上表及 `e81_results.json`。full AUC 下降 0.017176、late AUC 下降 0.027625，full/late 的AUC均为6/6退步；bACC与F1也整体下降。full 与 late 均未显示共同潜力，因此不扩展57人，也不进入后续训练。
