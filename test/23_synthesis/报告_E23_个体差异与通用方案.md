## 2. 被试画像与个体差异原因（B，`subj_profile.py` → `profile.csv` / `profile_corr.csv`）

画像只用校准块计算。各项定义：
- `d_top20`：块 0–1 与块 2–3 同号特征的最小 |d′|，取前 20 个的平均。
- `auc_cv5`：校准段内 5 折连续切片 LR 的 AUC。
- `auc_xblk`：用块 0–1 训练、块 2–3 测试，再反过来，两次 AUC 的平均。
- `drift_cos` / `drift_sign`：两组块效应量向量的余弦相似度，以及 top200 特征的同号率。
- `bias_shift`：跨块后 LR 两类中点的漂移量。
- `sim_*`：本人效应量方向与其他被试的余弦相似度。
- `d_{stft,dwt,hilbert,oth,emg}`：各特征组的一致性 d′。
- 频谱指标：从特征算相对功率；从原始 BDF 算 line50（48–52Hz 占比）、emg_hf（55–100Hz 与 1–45Hz 之比）、幅度和坏段比例。

Spearman 相关（n=56，BH-FDR 校正）：

| 目标 | 最强相关的画像项（rho，q 值） |
|---|---|
| ens8 bACC | sim_top10 +.66（q<.001）；sim_mean +.61；d_emg +.58；d_top20 +.49；d_hilbert +.49；d_cal_max +.48 |
| oracle−ens8 差距 | sim_top10 −.70（q<.001）；sim_mean −.64；d_emg −.60；d_top20 −.52；d_stft −.50 |
| 中位数阈值比 t0 好多少 | d_emg −.55（q=.001）；sim_top10 −.47；d_cal_max −.43 |
| 胜出配置含 sim/b23 | d_emg −.49（q=.006）；d_cal_max −.43（q=.019） |
| b23 优势 | rel_beta −.40（q=.05） |

线噪声（line50）、EMG 高频比例（emg_hf）、幅度、坏段比例和 alpha 反应性与上面任何目标都没有显著相关。数据质量不是个体差异的主因。

### 主要发现
1. **与他人是否同向决定通用模型的效果。** sim_top10 解释了 ens8 成绩的最大份额（rho=.66）。和群体方向一致的人，联合 LR（joint）直接达标：纯 joint 胜出者的 sim_top10 中位数 .69，ens8 中位数 .88。
2. **块间方向反转是最难的一类。** 21/56 人 top200 特征同号率 <.5，即块 0–1 与块 2–3 的效应方向大面积相反。这些人的 ens8 均值 .707，其余人 .779。胜出配置含 sim/b23 的 6 人（005、009、029、030、041、052）有以下特点：
   - drift_cos 中位数 −.20（其他人 .53，Mann-Whitney p=.02）；
   - auc_xblk .40（其他人 .62，p=.047）；
   - d_emg .42（其他人 1.10，p=.0003）。
3. **EMG/高频组的可分性代表"稳定的任务相关肌电/唤醒信号"。** d_emg 高的人 ens8 好（rho=.58），t0 阈值就够用。d_emg 低的人需要中位数/分位数阈值（rho=−.55）或近块模型。非 t0 胜出者的 d_emg 中位数 .84，t0 胜出者 1.46（p=.0001）。
4. **own（本人 LR）对哪些人有效没有清楚的画像特征。** own 胜出者与纯 joint 胜出者在 sim_top10、d_top20、auc_cv5 上都没有差异（p>.49），只有 ens8 更低（.83 对 .88，p=.03）。所以 own 加入集成更像是在 joint 已经接近 .9 的人身上做随机修正，选择偏差的成分较大。
5. **阈值偏移只部分解释分位数阈值的作用。** 非 t0 胜出者的 bias_shift .47，t0 胜出者 .23（p=.08，不显著）。

### 每种方法为什么有效（机理 → 对应被试）
- **joint（联合 LR）**：他人的数据提供稳定的群体方向，本人校准做对齐。适用于 sim 高、d_emg 高的人，例如 003、007、012、013、016、018、021、027 等 18 人。
- **因果中位数/分位数阈值**：抵消测试段的整体偏置漂移，不改变排序，所以能提升 AUC 已经不错（.86）但 bACC 被阈值拖低的人。C1 实验中，ens8 用 t0 时 AUC .810；改用因果阈值后 AUC .865，bACC 从 .748 升到 .766。
- **sim / b23**：适用于块间方向反转、群体方向不适用的人。b23 只用最近的块，sim 换成方向相近的人群，都是在"选方向"。对应 005、009、029、030、041、052。
- **idx / g / f**：特征少，方差低。适用于校准段有少数强一致特征、全维 LR 容易过拟合的人，通常与 joint 组合使用，起补充作用：idx+joint 有 001、010、025、037、038、056、059；g+joint 有 046、047、053；单独 idx/f 有 004、008、022。

## 3. 通用方案（C，`general.py` → `general.json` / `general_per_subject.csv`）

- **候选集**：在 `common.py` 中重建 E22 第 1–3 轮和第 6 轮的 57 个基础候选：joint×8、ens8、own×15、idx×5、f×5、g×10、idxg×5、sim×4、b23×4。再加上全部两两 z 平均，共 1653 个配置，配 8 种因果阈值（t0、m120/300/600、q300/600 × .4/.6）。
- **034 的处理**：joint/g/idx/f 换成跨被试版本（z 参考用块 3），own/sim/b23 不可用。
- **合规性**：
  - 本人只用校准块和测试段无标签的过去窗口（因果阈值）；
  - 选择器只用其他 56 人的画像和测试 bACC，这些属于历史数据；
  - 超参用内层 LOSO 选；
  - 没有用块序号、时间或次序位置作特征。
- **C1 固定大集成**：在 t0 下加入更多族反而变差（.748→.722）；在因果阈值下略好（.780）。各族分数直接平均会互相抵消，提升有限，而且不显著（p=.35）。
- **C2 元选择器**：只用全局最优（C2a）时 LOSO 只有 .712。原因是全局最优配置在留出一人后不稳定：前三名配置之间跳动，而 7 人被换到 `k4390_w0.6+sim800|t0` 后崩溃。加入画像后的 kNN 和岭回归恢复到 .79，说明画像确实带有"该用哪类方法"的信息。
- **C3 无监督自适应**：因果中位数/分位数阈值已在 C1 和 C2 的配置空间中，C2 经常选到它们。
- **仍然失败的人**：029 .06、009 .23、042 .41、052 .52 等，都是块间方向反转的人。测试段的方向与校准段的方向关系不确定，只靠校准画像无法判断该翻转还是保持。

## 4. 诚实结论

- 57/57 达标是 oracle 口径的结果。逐人在约 1.3 万个配置中按测试标签挑选，选择偏差很大。即使只有 1653×8 个配置，oracle 也能到 .939。
- 可部署口径的最好结果是 C2c/C2b：bACC .79，AUC .86–.87，F1 .79，n≥0.9 为 12–13 人。没有达标。
- 差距的主要来源是约 1/3 的被试块间判别方向反转（drift_sign<.5）。这些人测试段的方向在校准段里无法确定，所以无论用哪个配置，都要先"猜对方向"。其次是阈值漂移，因果阈值能部分修复。
- 下一步可做：
  - 用在线无标签数据判断方向，例如测试段与校准段两类原型的距离比较或 EM 双簇对齐；
  - 用更多被试的数据训练画像 → 方向的预测。
