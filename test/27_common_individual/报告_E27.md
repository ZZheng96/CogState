# E27：通用 + 个体子空间（w_i = a·w0 + U_k z_i + 因果阈值）

脚本 `e27.py`，结果 `e27.json`（table / per_subject / cvlog / diag / nested_select），逐人×85 阈值评估矩阵 `ev_*.npz`，日志 `e27_raw.log`、`e27_rest.log`。

## 方法

- 输入空间：逐窗原始特征 `test/11_individual_20261102/sliding1/*.npz`（878 维，1 帧/s，由 `17_compliant/loso.py` 的 `load()` 读入）。每人按本人校准段（块 0–3；034 只用块 3）做 z 标准化。四个特征集：
  - `raw`：878 维，直接 z。
  - `rc300` / `rc600`：先减去过去 300 / 600 帧的因果均值（在线重定心），再 z。
  - `cat`：E19–E23 用的 4390 维因果多窗 z 特征（w=60/120/300/600/全程累计）。
- 嵌套 LOSO，对每个被试 i：
  - 其余 56 人各自用全部 6 块拟合 ridge LR（λ=0.3），得到 w_j 并单位化。w0 是这些 w_j 的均值，U 是 (w_j − w0) 的前 5 个主成分。被试 i 本人的数据不进入 w0 和 U。
  - `k0`：只用 s0 = X·w0，即纯通用模型。
  - `kK`（K=1,2,3,5）：logit = c + a·s0 + Σ z_k·(X·U_k)。a 和 c 不罚，z 的 ridge 收缩向 0。用 Newton 法在本人块 0–3 上拟合。λ∈{1e-3…10}，在校准段内用「留一对块（R,T）」4 折，按平均 AUC 选。
  - `kcv`：k 也在校准段内按上面的 4 折 AUC 选。
  - `res`：全维个体项，logit = c + a·s0 + X·δ，δ 收缩向 0，相当于 w 收缩向 w0 的方向。`own`：只有 X·δ，即只用本人块 0–3 训练 LR。λ 都按 4 折选。
  - `pool`：其余 56 人全部帧的联合 LR，作为参照。
  - 组合：`kcv+own`、`kcv+pool`、`res+pool`，各分量用校准段统计 z 化后求和。
  - 034 没有放松类标签，所有需要本人标签的模型都退化为 k0。
- 决策：分数用本人校准段统计 z 化后，进入 e26lib 的 85 种因果阈值（t0、m60–m2400、q*）。阈值按 LOSO 选，即取其余 56 人平均测试 bACC 最大的阈值，被评被试不参与。`nested_select` 是外层再做一次 LOSO，同时选（特征集 × 配置 × 阈值）。

## 诊断（`e27.json` 的 diag）

- 个体子空间有效。cat 上 kcv 比 k0 高 10.6 个点，35/56 人提升。说明 w0 本身方向差，「通解」解释不了多少方差。
- 子空间不够。全维 own 和 res 都比 kcv 高 2 个点，33/56 人 own > kcv。PCA 前 5 维装不下个体方向，个体差异不是低秩的。
- 校准段内选 λ 和 k 几乎没有信息：
  - 全维 res/own 的留一对块 CV AUC 平均只有 .52–.64，测试 AUC 却是 .85。原因是用 2 块训练时，模型学到的主要是块身份（块偏移）。
  - kcv 的 CV AUC 与测试 AUC 的 Spearman ρ 只有 .11（cat）。
  - kcv 选中的 k 分布为：k1 26 人、k2 12、k3 8、k5 10，偏向小 k。
- 在线重定心（rc300/rc600）没有帮助，与 raw 基本持平（±.01）。因为决策层已经用 m300 做了重定心，特征层再减一次是重复的。并且 k0 在 rc 上更差（.63），说明去均值也去掉了一部分跨人共享的 tonic 信号。
- min 很低（cat res .022）。042 这类块间方向反转的人在任何线性 w 上都会被翻转，子空间也救不了。

## 结论

1. 「通解 + 特解」的结构成立：w0 加个体项明显好于纯通用（+10 至 +13 个点）。但个体项需要接近全维，k≤5 的 PCA 子空间只拿回一半。
2. 最好的可部署结果是 cat\|kcv+own@m300：bACC .797 / AUC .865 / F1 .785，n90=9。它没有超过 E24 的 .825，离每人 ≥.9 很远。
3. 瓶颈仍是块偏移。本人 20 分钟校准数据无法区分「个体方向」和「块漂移方向」，校准内 CV 对测试几乎没有预测力。所以 z_i 的估计质量受限，与模型结构关系不大。

## 下一步

- 把 E27 的 cat\|kcv+own 和 cat\|res 分数作为新的配置加入 E24 的分组候选池，看反转组或中等组能否改用它（预计 +1–2 个点）。
- U 改用「块差分」学习：在其余人上把 w_j(块 0–1) − w_j(块 2–3) 的主成分当作漂移子空间，估计 z_i 时把它投影掉（去掉漂移方向），而不是把漂移学进 z_i。
- 选 λ 的折改为「块内前半 / 后半」切分，避免折间块身份泄漏。
