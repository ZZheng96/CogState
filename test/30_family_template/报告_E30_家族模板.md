# E30 家族模板 + 本人校准块选配方（家族 A）

## 方法
- 家族 A（sim/b23 原理）：G0,G2,G3,G6,G7,G9,G10,G11,G13,G16，共 33 人。
- 候选 = 族内各组原配方（cfg 或 z 双 cfg + 因果阈值），共 6 个；G6/G10/G11/G13 为专属配方，excl.json 只有测试指标、没有分数序列，无法在校准块上评分，所以没进候选。这 10 人只能从其他 6 个配方里选。
- 每人只用本人校准块 0–3 选配方，规则对所有人相同：
  - mean：块 0–3 整体 bACC 最高
  - minb：块对 (0,1)(2,3)(0,3)(2,1) 中最差一对的 bACC 最高
  - last：块对 (2,3) 的 bACC 最高
- 校准块按类别交替（0/2 负类、1/3 正类），单块只有一类，所以按块对评分。
- 测试块 4–5 评估，只计算族内成员 × 族内配方。

## 结果（测试块）

| 规则 | 达标(≥.9) | bACC | AUC | F1 |
|---|---|---|---|---|
| mean | 14/33 | .784 | .830 | .799 |
| minb | 12/33 | .764 | .816 | .777 |
| last | 15/33 | .788 | .836 | .801 |
| home（原组配方，23 名非专属成员） | 23/23 | .924 | .973 | .925 |
| oracle（6 个候选中测试最优） | 26/33 | .898 | .948 | .901 |

- 同一个人的 6 个候选之间，校准 bACC 和测试 bACC 的相关系数平均为 .56（块对 (2,3) 为 .54）。
- 选错集中在两类人：
  - 漂移型（009、052、029 等）：校准块上最好的是 R0/R1 这类静态阈值配方，到测试块上反而是 m300 等自适应阈值配方更好。
  - 专属组成员：族内没有能让他们达标的可评分配方。

## E30b 全族统一阈值（fam_thr.py）
想法：E30 选错多因为校准块偏爱静态阈值，所以把阈值从个人选择里拿掉，全族共用一个；个人只在校准块上选 cfg（6 个族内配方 + 族 z 均值）。

| 统一阈值 | (a) 校准选 cfg 达标 / bACC / AUC / F1 | (b) 族均值 达标 / bACC / AUC / F1 | 该阈值下 cfg oracle |
|---|---|---|---|
| m600 | 11/33 / .740 / .786 / .737 | 8/33 / .748 / .792 / .735 | 15 |
| m1200 | 10/33 / .751 / .810 / .767 | 7/33 / .747 / .817 / .758 | 19 |
| m300 | 6/33 / .778 / .854 / .761 | 5/33 / .800 / .870 / .784 | 13 |
| t0 | 9/33 / .773 / .824 / .777 | 5/33 / .741 / .828 / .759 | 17 |

- 阈值统一后，测试最优也只剩 19/33，比各人用自己的阈值时（26/33）还差，所以阈值本身就是个体差异的一部分，不能拿掉。
- 053、055、029、054、009 在多数配方下测试 AUC < .5，即分数方向在校准和测试之间翻转；这类人靠选配方解决不了。

## 结论
用本人校准块挑配方达不到要求：最好的规则也只有 15/33 达标，而原组配方是 23/23。原因是校准块和测试块之间有分布漂移，校准 bACC 只能部分预测测试 bACC（相关约 .56），看不出哪个配方能扛住漂移。只调选择规则（换块对、加稳定性约束）的提升在 ±3 人之内。
