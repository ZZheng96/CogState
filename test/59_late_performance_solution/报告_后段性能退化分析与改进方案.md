# 后段性能退化：分析逻辑与改进方案

## 最新改进计划（E59 后更新）

> 以下为当前建议；后文第 4–6 节保留的是 E59 前的方案与决策，不再作为待执行计划。

### 当前结论

- 基线全段：AUC **0.8315** / F1 **0.7742** / bACC **0.7824**；后段块 4–5：AUC **0.7601** / F1 **0.7130** / bACC **0.7282**。
- E59 最佳后段 bACC 候选仅达到 **0.7284**，后段 AUC **0.7603**、F1 **0.7130**，没有实质解决退化。
- 较强修正可提高后段 AUC，但会损伤全段表现。例如 `dual_h120_w50_c50`：全段 AUC/F1 **0.8249/0.7684**，后段 AUC/F1 **0.7673/0.7079**。
- 固定权重 `dual` 已持续工作，其“触发率 0”是诊断字段口径，不代表没有修正；本次限幅采用分数绝对单位，并非原方案建议的训练折标准差倍数。
- 当前不改正式主链，不继续盲目扩大均值适应参数搜索。

### 评价与合规要求

- 以全段 AUC 为主要指标，后段 AUC 为关键辅助，同时报告 F1、bACC、逐被试变化和最差退步；不能只按后段 bACC 排名判断优劣。
- 使用同一套留出分数反复筛选仅属探索。最终验证需将目标被试与模型训练、阈值及候选选择完整隔离；不能把缓存分数上排除目标被试的选择直接视为完整嵌套重训。
- 在线只使用当前及历史 EEG/分数；不读取测试标签、未来样本或离线 block 边界，不人工选择个体方案。
- 从第一帧按协议输出，不回改历史结果；正式输出状态及连续评分，明确高分对应 task。
- 候选通过离线验证后，再检查真实 BDF 流式推理、不同 chunk 一致性和前缀不变性。

**决策原则：先判断哪些退化可以校准修复，哪些已丢失判别能力，再决定修后处理还是重新训练。软适应更平滑，不代表必然更有效。**

## 1. 问题定义

当前严格 LOSO 基线为：

- 全段：bACC **0.7824** / AUC **0.8315** / F1 **0.7742**；
- 块 4–5：bACC **0.7282** / AUC **0.7601** / F1 **0.7130**；
- 低组块 4–5：bACC 约 **0.568**。

因此，后段性能下降是拖累整体指标的重要群体现象，但不代表所有个体都以同一种机制退化。

## 2. 分析过程

### 2.1 先排查信号非平稳

对原始 BDF 提取时域、频域和信号质量指标，并分析这些指标与错误增加的关联。多重比较校正后，没有足够证据证明低组后段存在统一的生理信号质量变化，也不能确认疲劳、注意力或电极状态是唯一原因。

结论：只能确认后段性能/可分布发生变化，不能直接把它定性为已证实的生理非平稳。

### 2.2 波形前后段交换

将表现较差个体的前后段波形交换，观察模型性能变化：

- 早段波形放到后段后，后段性能只有小幅恢复；
- 后段波形放到早段后，早段性能明显下降。

这支持“输入内容或个体状态参与退化”的判断，但交换会破坏自然时间上下文，不能单独证明具体生理机制。

### 2.3 检查后处理历史依赖

当前主链包含 causal detrend 和 forward HMM。通过比较原始分数、无 HMM、仅重置 HMM、仅重置 detrend、同时重置两者，发现：

- 仅重置 HMM 的收益很小；
- 重置 detrend 在总体缓存上有明显收益；
- 每 block 同时重置在缓存消融中最好，但真实 BDF 个体验证显示收益不一致。

因此，历史状态可能放大部分个体的后段退化，但不是所有个体的共同原因。

## 3. 为什么硬重置会让部分个体退步

重置 detrend 并不只是删除噪声，而是重新定义当前分数的零点。若某个个体原本依赖跨 block 的长期基线，重置会造成：

1. 新 block 的起始分数被误当成新的基线；
2. task/relax 的相对分数被重新平移；
3. 原本有用的跨 block 连续性被破坏；
4. HMM 若同时重置，还会丢失有效的状态先验。

真实 BDF 核验表明，退步个体并不都原先有后段退化：

- **018**：原先后段没有下降，重置后下降，说明重置破坏了原本有效的连续状态；
- **010**：原先有后段下降，但重置后灾难性恶化，说明其问题不能简单用重置修复；
- **050**：原先有后段下降，重置只在严格后段局部改善，但全段变差；
- **009**：原先没有后段下降，重置 HMM 后反而改善。

结论：后段退化与后处理历史失配不是等价问题。重置收益高度个体依赖，不能统一部署。

## 4. 更好的解决方向

不再采用“到边界就清零”的硬重置，优先尝试**连续、受限、无边界依赖的软适应**。

### 4.1 双时间尺度 detrend

同时维护长期和短期基线：

```text
long_mean  = EMA(raw_score, halflife=1200)
short_mean = EMA(raw_score, halflife=60~600)
base = (1-w) * long_mean + w * short_mean
adjusted_score = raw_score - base
```

其中 `w` 不是按 block 固定切换，而由持续漂移证据逐步调整：

- 长短期差异小：保持 `w≈0`；
- 长短期差异持续变大：缓慢增加 `w`；
- 漂移消失：缓慢降低 `w`。

必须限制最大修正幅度，避免短期异常直接改变整段方向。

### 4.2 保留 HMM 连续状态

第一轮只改 detrend，不重置 HMM。现有结果显示 HMM 的连续性对部分个体有保护作用，同时重置 HMM 会放大 010 型个体的退化。

### 4.3 稳健、限幅的基线更新

可比较以下简单版本：

```text
correction = clip(short_mean - long_mean, -c, c)
```

或对基线更新量进行 clip/Huber 限制，使异常分数不会快速污染长期状态。候选持续时间可取 30、60、120 帧。

### 4.4 只对持续漂移触发

不使用 block 边界、不使用标签、不使用未来数据。可用的无标签证据包括：

- 长短期分数均值差；
- 分数方差变化；
- raw 与 HMM 输出的持续分歧；
- 最近 60–120 帧的符号翻转率。

触发后的动作只能是增加短期基线权重或有限修正，不能立即清零。

## 5. 建议实验顺序

### 实验 A：双基线软混合

在已有 57 折 LOSO 分数上快速测试：

- 长期 halflife：1200；
- 短期 halflife：60、120、300、600；
- 短期权重：0.1、0.25、0.5；
- HMM 保持 dwell=300。

### 实验 B：限幅修正

测试最大修正幅度为训练折分数标准差的 0.1、0.25、0.5 倍。

### 实验 C：严格因果筛选

每个候选必须报告：

- 全段 bACC/AUC/F1；
- 块 4–5 bACC/AUC/F1；
- 低组后段；
- 个体 004、009、010、018、050；
- 最差个体和触发比例。

建议接受标准：

- 全段 bACC 不低于 **0.7774**；
- 全段 AUC 不低于 **0.8265**；
- 全段 F1 不低于 **0.7692**；
- 块 4–5 bACC 至少提升 **0.01**；
- 不允许出现 010 型灾难性退化；
- 不依赖 block 边界、标签或未来数据。

只有通过 LOSO 筛选，才进入真实 BDF 流式验证。

## 6. 当前决策

当前正式部署仍保留：

```text
E17 LR + 3-seed MLP
→ 训练折尺度融合
→ causal detrend halflife=1200
→ forward HMM dwell=300
```

不采用：

- 统一 block 重置 detrend；
- 同时重置 detrend 和 HMM；
- 无标签方向翻转；
- 直接统一缩短 detrend halflife。

最合理的下一步是：**先在已有 LOSO 分数上实现双时间尺度、限幅、连续软适应实验；若不能同时改善后段并保护正常个体，则继续保持现有主链。**

### 失败原因

- **修正对象可能不对**：050 后段 AUC 仅 **0.0354**，表现为反向排序，不是简单阈值偏移；均值校准无法直接解决。
- **软适应存在取舍**：修正弱时几乎无效，修正强时可能把真实任务信号一起减掉，损伤全段 AUC/F1。
- **初始化不是当前主要突破口**：更换初始中心收益很小。
- **时间均衡没有改变判别方式**：后段 AUC 从 **0.4819 到 0.4931**，仍接近随机，F1 未改善。
- **根因尚未定位**：还不能确定反向排序来自原始模型、融合、后处理，还是时间与标签对应问题。

### 下一步方案

1. **停止扩大 detrend 参数搜索，保持正式主链不变。**
2. **优先检查 050、009、010、004**：核对时间、标签、缓存及留出模型身份。
3. **拆开计算 LR、MLP、融合、detrend、HMM 的前后段 AUC/F1**，定位反向排序首次出现的环节；同时检查分块分布，区分块内失效与块间偏移。
4. **按定位结果改动**：
   - 单个模型失效 → 调整融合；
   - 后处理引入反向 → 修改对应后处理；
   - 原始模型均失效 → 改特征与训练方法，不再靠分数平移补救。
5. **参数只用训练折选择**；小样本确认方向后再跑全体 57 折，不按测试标签翻转方向。
