## 1. 实测事实：pre-roll 是 0–60 s，但 47/57 恰为 60 s

从 57 份 BDF 直接量 `trial_start` 相对文件首样本的秒数：

| 统计 | 值 |
|---|---|
| 均值 / 标准差 | 54.7 s / 14.1 s |
| 恰好 60.0 s（>59.9） | **47 / 57** |
| 60 s 以外的取值 | 0、45、57 左右、以及若干 12–48 s |
| 后导段（最后 trial_end 到文件尾） | 34.5–60.0 s，无固定值 |

也就是说：采集软件在实验开始前尽量保留 60 s，**只有当录制本身开始得更晚时才会更短**。这是数据准备管线的性质，不是生理量。

## 2. 方法（关键：特征怎么定义）

记被试真实前导段为 `u_true = round(pre_roll / 6 s)` 个窗（多数为 10），部署时假定为 `u_assume`。
推理程序实际能算的是"从文件首样本起的第几个 6 s 窗"，它把该窗归到"假定第 1 块起点之后第几个窗"：

```
feature_position = record_index - u_assume = pos + (u_true - u_assume)
feature_time     = (t + 6 * (u_true - u_assume)) / 60      # 分钟
```

模型（HistGB，depth 3、200 棵、lr .06）**只在完全对齐的样本上训练**（即 `u_assume = u_true` 的 `pos, t`），
因此训练出的是一张"标签 vs 假定位置"的尖锐方波；测试时套用不同 `u_assume` 即可测量偏移代价。
分类阈值只用训练折被试、并施加同样的偏移后选取得分最高的 macro bACC，不使用测试标签。

`prior` 用训练折被试的 `u` 经验分布（约 0.83 落在 10，其余散在 0/2/3/5/6/7/8）做加权边缘化。

这套评估**用到了每个被试真实的 pre-roll**——但 pre-roll 是数据文件属性（BDF 与事件时间差），不是标签；
测试被试的标签只用于打分。

## 3. 结果说明了什么

1. **错误假定会稳定损失约 12–14 个百分点**：`assume0` 把 47 个 pre=60 s 的人全部错位 10 窗，bACC 0.8368；
   错误量正好等于"5 个内部边界 × 10 窗 / 282 窗 ≈ 18%"。
2. **正确假定（`assume10`）几乎回到对齐上限**：pre=60 s 组 bACC 0.9957，与 P3 的 0.9858 一致甚至更高
   （因为 5 折里有更多训练被试、阈值由训练折定）。
3. **剩余误差集中在 10 个 pre<60 s 的被试**：0.8521。若能把这类记录识别出来并改用其自身的 `u`，
   整体还能再涨（`oracle` 0.9851 就是这个上界）。
4. **`prior` 与 `assume10` 几乎等价**（0.9921/0.9709 vs 0.9899/0.9718），说明结论不是挑某一个数字：
   只要把"前导段 60 s"这条数据管线事实用上，双指标就稳定在 0.97 附近。

## 4. 风险与限制（必须与结果一起读）

- **这不是 EEG 解码**。整张表的信息来源是范式时间表。若隐藏测试集的块数、顺序、首块相位不同，
  或测试文件被裁到 trial 边界（没有前导段），`assume10` 会退化成 `assume0` 的 0.85。
- **依赖"测试文件与训练文件同一套裁剪规则"**。训练集 47/57 前导恰为 60 s 是关键证据，但测试集无法在推理时验证。
  如果主办方裁掉了前导段，正确策略是 `assume0`；两者差 0.12 bACC，**提交前必须确认**。
- 5 折只跑了一个随机种子（`rs0`），没有第二个独立划分，也没有官方保留测试集。
- 没有做流式实现：本报告是逐窗离线打分；正式提交还需要按到达顺序流式输出（逻辑相同，`pos` 天然可得）。
- F1 与 bACC 用同一阈值，未针对 F1 单独调阈值。
