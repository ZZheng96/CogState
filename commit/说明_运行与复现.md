# 运行与复现说明

## 1. 环境

- Python：建议 3.11
- 依赖：`pip install -r requirements.txt`
- 输入：250 Hz 单通道 EEG，单位与 MNE/BDF 读取结果一致；分块按时间顺序传入。
- 输出：每 1 秒输出 `(t_end, score, state)`；`score>0` 表示 task，`state=1` 表示 task，`state=0` 表示 relax。

## 2. 流式接口

```python
import sys
import torch
sys.path.insert(0, "code")
from streaming import StreamingInference

bundle = torch.load("model/model_bundle.pt", map_location="cpu", weights_only=False)
engine = StreamingInference(bundle, fs=250, step=1.0)
for t_end, score, state in engine.update(eeg_chunk):
    print(t_end, score, state)
```

`eeg_chunk` 可以是任意长度的一维数组。缺失或不连续区间调用 `engine.mark_invalid()`；切换被试调用 `engine.reset()`。

## 3. 本地最小示例

在项目根目录执行（提交包位于项目根目录的 `commit/`）：

```powershell
.venv\Scripts\python.exe commit\code\streaming.py demo --subject 018 --chunk 0.37
```

该命令读取项目根目录 `EEG_dataset` 的 BDF 和 events CSV，仅用于本地烟测；正式提交时不得读取测试标签，不得运行训练命令。截图需在实际终端窗口中补充，不能用 IDE 画面替代。

## 4. 算法配置

- 6 秒原始窗口，250 Hz；每 1 秒决策。
- 多尺度因果统计：60、120、300、600、99999 帧。
- LR：C=0.001。
- MLP：seed=0、1、2，输出均值。
- 条件化门控：120 帧因果 rolling 特征，C=0.1，半收缩系数 0.5。
- 后处理：EMA1200 + forward HMM300。
- 全部预处理、特征、门控和后处理只使用当前及历史样本。

## 5. 结果依据

严格完整嵌套 LOSO：全段 AUC=0.841660，F1=0.774756，bACC=0.788747。结果文件位于 `experiment/nested_loso/`。

E87 全量训练逐被试结果仅表示训练集内拟合，不是新被试泛化结果。
