数据说明

每个编号文件夹包含一个 .bdf 脑电文件和一个事件 CSV 文件。
数据集共 57 份记录，不含 032 和 033。

脑电文件
  格式为 BDF+C，单通道，采样率为 250 Hz。
  实验前后各保留最多 60 秒可用脑电，不足 60 秒时不补齐。
  缺失区间补零并标记为 BAD_ACQ_SKIP，分析时请排除。
  BDF 文件头和事件 CSV 均使用北京时间（UTC+08:00）。
  脑电文件名给出第一个样本的精确时间，包含毫秒；第 n 个样本的时间为
  文件名时间加 n/250 秒。

CSV 字段
  local_time：事件发生的北京时间（UTC+08:00）。
  event：事件类型，见下文。
  phase：relax 表示放松，task 表示操作机械臂放置积木。
  key：按键名称；阶段开始、结束记录中为空。

事件含义
  trial_start：当前阶段开始。
  trial_end：当前阶段结束。
  key_press：通过 Enter（回车）或 Space（空格）确认完成一次木块搬运。
             确认后显示约 1 秒反馈，再给出下一个搬运任务指示。
  task_failure：主试通过 Backspace（退格）记录一次放置失败。

划分放松和任务状态时，将每条 trial_start 与其后的 trial_end 配对，
该时间段的状态由 phase 决定。trial 指一整段放松或任务，不是一次木块搬运。
请使用实际事件时间和阶段时长，不要假设每个阶段都是 5 分钟。
实验阶段以外的前后脑电没有状态标签。
