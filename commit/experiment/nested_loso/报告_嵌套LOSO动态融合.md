# 嵌套 LOSO 条件化动态融合

严格外层57折LOSO；每个目标被试完全留出。其余56人按确定性 seed=76001+外层折、7个被试组内层折生成基础LR/MLP OOF分数，再仅用这些OOF分数训练 Logistic gate。基础模型为E42固定多尺度特征、LR C=.001、MLP seed 0/1/2均值；尺度仅由对应训练被试估计；门控特征为lr、mlp、abs_diff及窗口120的严格因果滚动均值/std。后处理统一 EMA1200 + 前向HMM300，阈值0。

## 与原E74/E76的关系与限制

本实验不读取原E74/E76结果或组件缓存作为训练输入，独立重训所有外层基础模型并独立缓存；因此与原E74固定融合及原E76直接复用E74组件的数值不可视为同一缓存链路的逐点复现。conditioned_shrink为预声明的半幅收缩对照，未用目标被试标签调参。窗口统计严格只含当前及过去帧；外层目标标签只用于最终评价。
